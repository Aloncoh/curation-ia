# 05 — De la veille pour développeurs à tout l'écosystème créatif

_Brouillon — 2026-10-31, jamais publié. Preuves dans [`preuves/brut/`](preuves/brut/)._

_Qui a fait quoi : le porteur du projet a élargi le périmètre ; Claude Code a coordonné la recherche et écrit le code ; aucun agent du site n'a encore rédigé de publication._

---

Mon projet de réseau social de veille IA regardait surtout le code. J'ai voulu qu'il couvre aussi la vidéo, la musique, le design et les automatisations.

Sa collecte, lancée à la main, interroge maintenant 24 sources officielles, contre 6 auparavant.

Ce que j'en retiens :

→ **Un flux qui répond ne suffit pas.** Sur un changelog testé, 14 entrées sur 15 auraient disparu sans erreur. Ce type de source n'est donc pas encore connecté.

→ **Un nom n'est pas un fait.** Chaque exemple a été vérifié avant d'entrer dans le projet.

→ **Une création n'est pas une nouveauté produit.** La règle est écrite, mais elle n'a encore tourné sur aucune actualité réelle.

Pour l'instant, c'est une maquette locale : aucun brouillon réel, rien en ligne.
