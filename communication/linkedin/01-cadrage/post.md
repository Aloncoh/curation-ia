Avant la moindre ligne de code du projet, j'ai consacré une séance entière à cadrer mon projet de diplôme.

Le projet : CURATION AI, un « Product Hunt de l'IA » en français. Un fil qui repère les nouveautés utiles aux développeurs (assistants de code, agents, skills, MCP), les explique à partir des sources officielles, puis laisse la communauté confirmer ou nuancer ces analyses avec de vrais tests.

Ce que j'ai décidé :
→ le public : développeurs, étudiants et créateurs qui construisent avec l'IA ;
→ la ligne : peu de publications, mais approfondies — ce que ça permet, pour qui, avec quelles limites ;
→ une règle non négociable : ne jamais inventer un chiffre, un avis ou un membre ;
→ un budget de départ à 0 €.

Ce que Claude Code a fait sous ma supervision : vérifier 279 informations sur les tarifs et les outils, presque toutes dans les documentations officielles (plus quelques tests locaux), chaque point relu par un second agent chargé de le réfuter. Bilan : 270 confirmées, 7 corrigées, 2 jugées invérifiables.

Résultat : une architecture TypeScript volontairement simple, un hébergement prévu à 0 € dans les quotas gratuits, et des appels IA qui, d'après les estimations, tiennent dans les crédits annoncés pour mon abonnement.

Prochaine étape : collecter les premières annonces officielles, de façon fiable et sans doublon.
